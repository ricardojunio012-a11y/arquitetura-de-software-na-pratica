# Arquitetura de Software na Prática: código dos laboratórios

Código dos laboratórios do livro *Arquitetura de Software na Prática*, de Ricardo Júnio Gonçalves Filho (Coleção Na Prática).

Cada capítulo tem a sua pasta em `codigo/capNN/`, com um `README.md` que explica o roteiro. Os laboratórios rodam com Docker e Docker Compose; o Apêndice A do livro explica como preparar o ambiente.

Este repositório tem, por enquanto, os laboratórios do Volume 1 (capítulos 1 a 14).

Encontrou um erro no livro ou no código? Abra uma issue.
